# 第五阶段交互验收

| 项目 | 验证方式 |
| --- | --- |
| 数量/百分比/对数 | 实际图表截图发生变化，比例轴和 log10 提示正确 |
| 类别联动 | 筛选 F 后中心数量和分区提示同步 |
| 真实标注 | 专家标注 sample 与详情/API annotation_sample 一致 |
| 三模型 | API 返回三个不同 model_id，固定同一真实样本；概率来自各自返回值 |
| 模型切换 | Random Forest 高亮改变，原样本位置保持 |
| 概率联动 | 同一类别在三个卡片同步强调 |
| 前后心拍 | 相邻真实标注位置切换；返回原样本 |
| 历史回放 | RAF 游标推进；暂停后 data-time 保持；seek 后继续；0.5/1/2/4 倍 |
| 减少动画 | 系统 reduce 覆盖用户模式，波形 animation-name 为 none，功能仍可用 |
| 图库/实验/答辩 | 沿用完整回归：键盘与缩放、真实错误案例、八步演示和失败恢复 |
| 窄屏菜单 | 745px Tooltip 可读，展开完整菜单名，导航后折叠 |
| 溢出/异常 | 五尺寸浏览器截图与 body 宽度检查、pageerror 检查 |

完整回归：16 passed (5.2m)。独立生产：1 passed (26.9s)。五尺寸截图：5 passed (1.0m)。

真实三模型返回保存在 interaction/verified.json；故障注入仅用于测试请求失败、延迟和缺图，不充当医学数据。
