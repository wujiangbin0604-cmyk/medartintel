# Heartbeat Hunter 玩法与视觉设计

交付日期：2026-11-04。

## 入口与主要流程

- `/interactive-lab`：单款游戏入口、玩法简介、按难度个人最高分和最近记录。
- `/interactive-lab/heartbeat-hunter`：选择难度 → 开始 → 真实波形定位 → 提交或到时结算 → 逐拍揭晓 → 教学解析 → 下一关或重玩。
- 每轮五关，同一轮不重复关卡。每关独立计时、计分，并显示累计分数。
- 刷新恢复本地保存的随机会话；已结算会话不会再次发奖。

## 视觉

复用平台 MedicalLayout、Ant Design、Motion 和 ECharts。沿用用户参考图的浅色医学科技风：背景 `#F7FAFF`，主色 `#1677FF`，青蓝 `#06B6D4`，正文 `#182B49`，次要文字 `#64748B`，正确 `#16A34A`，错误 `#EF4444`。粉色仅表示玩家选择和结算后的专家 V 组。

中央原始 ECG 保留真实时间、采样率、记录、导联及 mV 振幅。右侧任务、五关进度、统计和可折叠提示。底部显示逐拍解析、实际局部波形、模型对比和成绩历史。不添加虚构游戏入口。

1920、1440、1366 桌面布局保持主波形优先；窄屏右栏转为下方网格。内容较多时正常纵向滚动，避免挤压波形。候选快捷按钮同时支持键盘操作。

## 状态与交互

状态：idle、loading、playing、paused、submitting、revealing、finished、error。提交和开始动作使用互斥锁；已结束会话不能再选择。ECharts 点击坐标换算成真实绝对 sample_index；新手仅在明确容差内吸附至所有候选中的最近心拍。标准和挑战不预先提供候选标注。

玩家可再次点击取消、关闭时间标签移除，再重新选择位置。所有选择向服务端按序保存；提交等待未完成的选择保存。答题期间连击与分数不预判，提交后按选择时间顺序揭晓。

## 动效和声音

- Motion 标题进入、连击数字弹跳、计分反馈出现/消失。
- ECharts 波形进入、标记增长、选择区域高亮、结果颜色和逐拍积分。
- CSS 单次选择扩散环；无持续装饰动画。
- requestAnimationFrame 驱动真实时间扫描；挑战模式按照历史回放位置移动 6 秒窗口，ECharts 视窗更新节流。
- 分数通过 requestAnimationFrame 过渡。计时每 150 ms 更新显示，以服务端剩余时间为锚点。
- 新手服务端暂停；其他难度禁止暂停。页面卸载清除 rAF、计时器、ResizeObserver、ECharts 实例及主要请求。
- 系统 prefers-reduced-motion 与平台减少动效设置均生效；关闭装饰扫描和 CSS 动画，保留必要的回放窗口变化。
- 原创 Web Audio 正弦提示音；默认静音，可主动开启、关闭及调节音量。

## 教学边界

目标使用 AAMI V 组（原始 V/E），页面不把 V 泛化为全部疾病；N 组也不等于完全正常。波形提示仅作为观察线索。游戏分数是娱乐学习积分。LR、RF、CNN 对比复用已有推理 API，必须在结算后主动调用，完全不参与评分。
