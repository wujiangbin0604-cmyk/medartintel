# 历史 ECG 回放行为

## 用户操作

用户选择记录、任务、导联、起始秒数和 1–30 秒时长后，点击“播放历史片段”。浏览器请求 `/api/ecg/playback/segment`，收到真实波形、该片段专家标注和允许运行时的批量模型预测。预测在片段加载时一次性生成并缓存在页面内，播放时不逐心拍重复调用推理接口。

页面支持暂停/继续、停止、回到起点、0.5×/1×/2×/4×速度和时间滑块。回放游标移动到一个标注之后，右侧单拍面板跟随显示最近一个任务内标注。seek 在已载入片段内定位，不会重新读取原始文件。

## 模型和标注规则

- 可推理记录且选择 MLII：按所选任务和最多三模型进行批处理，最多处理 128 个标注心拍位置。
- 排除记录或非 MLII 导联：仍返回实际波形及专家标注，预测数组为空，显示明确原因。
- 非心拍、未映射、Q 类或其他超出当前任务的标注保留在时间轴，但不进入模型批处理。
- 记录边缘、5 秒双向滤波保护区、固定窗口越界、无效或平直波形按训练数据技术规则拒绝预测。

回放是 MIT-BIH 已采集的历史数据，不模拟实时患者、传感器流、告警或临床监护。页面会明确显示“不是实时监护”。
