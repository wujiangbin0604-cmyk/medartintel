# 课程演示指引

1. 启动后端和前端，打开 `/ai-detection`。确认顶部“本地数据就绪”。
2. 选择记录 200，任务先选 N/V，导联选 MLII。查看受试者分区、采样率和 10 秒真实 ECG。
3. 点击图上一个标注点或图下标注快捷按钮，查看原始符号/AAMI 类、标注样本位置、原始与 0.5–40 Hz 训练滤波窗口。
4. 演示 CNN 单拍结果，再点击“比较三个模型”，比较 LR、RF 与 CNN 的预测类别、未校准概率、专家标签和推理耗时。
5. 切换 N/S/V/F，观察任务标签范围变化。Q、非心拍、未知类和越界位置不会作为目标心拍输入。
6. 点击“播放历史片段”，演示暂停、倍速与 seek。说明批量模型结果在加载片段时生成，显示的游标只在历史记录上移动。
7. 选取一个或两个心拍加入形态对比，可看到以标注点对齐的真实 mV 波形。

## 讲解边界

- 样本的 expert label 是现有 WFDB 专家标注，只用作展示和事后比较，不参与模型输入。
- “训练/验证/测试”是本项目原有受试者分组；测试 split 已在课程实验中查看过，不作为此工作台的独立临床验证。
- MIT-BIH 记录不是普通人群患病率样本。准确率不等于临床诊断质量，概率也未经临床校准。
- 这是静态历史记录回放，不连接病人或医疗设备，不发送临床警报。
