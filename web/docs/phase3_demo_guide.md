# 课程答辩演示指南

入口：`/presentation-demo`。八步引导直接嵌入真实页面，支持上一页、下一页、点击步骤、退出与浏览器全屏；进入第 2 步会读取记录 200 的 MLII 导联 6–16 秒窗口。示例来自现有 WFDB 文件；原实验分区为 train，不应称为独立新患者验证。

## 推荐本地运行方式

在项目根目录先执行 `npm --prefix web/frontend run build`，再执行：

```powershell
.venv\Scripts\python.exe -m uvicorn web.backend.production:app --host 127.0.0.1 --port 8002
```

打开 `http://127.0.0.1:8002/presentation-demo`。生产服务在同一来源提供构建文件和 FastAPI；课堂演示无需外网，无需启动 Umi 开发编译器。

开发时仍可分别运行原后端 8000 与 `web/frontend` 内 `npm run dev`（8001）。自动验收使用独立 8130/8131 端口。

## 八步流程

1. 介绍项目：48 条完整本地记录，四分类 100,115 条有效心拍，N/V 与 N/S/V/F，六个已保存模型工件（每个任务三种模型）。这些数值由真实接口计算。
2. ECG 波形：展示 200 / MLII / 6–16 s；时间单位 s，幅值 mV，浅色辅助网格不表示标准校准心电纸。
3. 专家标签：自动选择该窗口内第一个可用 N/V 心拍，可点击其它标注按钮；展示原始符号、AAMI、时间和样本位置。
4. CNN 推理：点击“运行 1D-CNN 推理”再次调用后端。区分专家参考标签与 AI 预测；概率未校准。
5. 三模型比较：点击“比较三个模型”，对齐 LR、RF、CNN 的类别、最大类别概率、参考匹配与耗时。三者一致不等于临床诊断正确。
6. 历史回放：点击播放，暂停、继续、回到起点、倍速、拖动进度。模型输出在载入片段时真实批量计算，播放期间复用结果。
7. 结果比较：切换两个任务的 Tabs，切换混淆矩阵模型与行归一化。强调四分类少数类指标而非仅 Accuracy。
8. 局限与总结：test F 类 371 拍中 370 拍来自同一患者；说明 S/F 稀疏、集中度与跨折波动。总结真实信号、推理、评估与错误诊断完整链路。

## 操作注意

先检查页头“本地服务与模型就绪”。初始化失败时有重试；查看模型文件缺失提示后，修复本地文件并重启服务。默认模型仅接受 MLII；未纳入实验的记录仍能浏览波形。起始 5 秒附近为训练过滤保护区，可展示但不可预测。切换记录、任务、导联、时间窗口会清理旧推理和回放状态。不要在演示中训练模型或改变既有结果。

本轮运行证据、截图和最终通过情况见 `phase3_interaction_testing.md` 与 `phase3_final_report.md`。
