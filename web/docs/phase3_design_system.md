# 第三阶段设计系统

执行日期：2026-11-03（Asia/Shanghai）。保持 Umi Max / React / TypeScript / Ant Design / ECharts；没有重建项目或更换模型。

## 视觉方向

蓝白医学科研工作台。将深蓝用于平台身份与信号主线，将亮蓝用于主要操作、选中心拍和研究重点。总览以真实项目说明与 ECG 线条为入口，波形工作台以信号为中心；避免装饰图占用分析空间。总览 ECG 线条明确标记为装饰，不作为医学数据。

## 排版与间距

使用本机 Segoe UI / Microsoft YaHei / PingFang SC，不请求外部字体。页面标题 28px，区域标题 16–18px，正文 14px，辅助信息 12–13px，核心数字 30px。时间轴与指标使用固定数字宽度。原界面 8–11px 的小字提升至至少 12px。

基础间距 8px，页面内边距 32px，主要网格间距 24px，面板内边距 20–24px，圆角 8px，避免大面积阴影。1366/1440px 下控制栏 232px，中央波形占余下宽度，详情通过 Drawer 查看；宽屏使用三列布局。手机改为单列。

## 组件规则

- 导航使用真实路由、活动状态和 `aria-current`，移除原无效菜单。
- ECharts 使用 ResizeObserver，销毁实例时同时断开 observer。波形播放游标单独更新，不在每帧重建整个图表。
- 图表有标题、单位、来源、简明解释；训练日志与历史 test 指标分别注明来源。
- 请求包含 30 秒超时和取消，数据源改变会清理旧结果。错误有可操作重试；空列表有筛选提示。
- 缩略图 `object-fit: contain`，大图保持原始比例；每页 12 张，原图按需加载。
- 键盘焦点可见、表单有可访问名称、尊重减少动画偏好。
- 本轮只交付浅色主题；原项目没有可用深色主题，不增加未验证的切换入口。
